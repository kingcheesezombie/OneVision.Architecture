# OneVision Architecture Explorer

Interactive, static documentation of the OneVision application landscape, functional capabilities and integration contracts. This catalogue is not an operational monitoring tool.

Hosted on GitHub Pages. Architecture definitions are stored in `data/architecture.json`. Public content only: never store internal hostnames or secrets.

The initial model covers IDM, EAM, HDM, KPI, ODM, OneVision hub and OneVision.UI. Relationships labelled planned are future concepts rather than deployed integrations.

To deploy: select **Settings → Pages → Build and deployment → GitHub Actions**, then the `Deploy architecture site to GitHub Pages` workflow publishes the site.
